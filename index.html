Sağ üstteki ayarlar simgesinden OpenAI, Gemini, OpenRouter veya uyumlu başka bir API seç. Anahtarını ekle ve model adını kontrol et.

Vitrini oluşturduktan sonra önizlemeyi gör, projeyi kaydet veya tek dosyalık web sayfası olarak dışa aktar.
